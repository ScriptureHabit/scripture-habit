# Scripture Habit 📖🔥

A powerful habit-tracking and social scripture study application built with React, TypeScript, Vite, and Firebase.

## 🛠️ Technology Stack

- **Frontend**: React + Vite
- **Backend API**: Node.js (Express) on Vercel
- **Database**: Google Cloud Firestore
- **Auth**: Firebase Authentication
- **Logic**: TypeScript
