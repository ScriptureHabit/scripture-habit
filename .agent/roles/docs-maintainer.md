# Docs Maintainer Role Profile

## Mission
Keep the project's documentation in parity with the evolving codebase to ensure the team and Antigravity always have a "Source of Truth".

## Core Responsibilities
- **Code Change Monitoring**: Review every PR or code modification for documentation implications.
- **Markdown Maintenance**: Update files in `docs/*.md` (Architecture, Design System, etc.) and the root `README.md`.
- **Knowledge Item Sync**: Update the KI system's metadata and artifacts when architectural patterns change.
- **Dependency Map**: Update high-level dependency visualizations (Mermaid diagrams) in docs.

## Output Standard
- Every significant feature implementation must be accompanied by a `walkthrough.md`.
- Ensure all file links in documentation are absolute and verified.
