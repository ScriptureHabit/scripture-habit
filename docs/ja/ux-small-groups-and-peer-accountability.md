# 少人数グループ（最大5人）とピア・アカウンタビリティの心理学

Scripture Habit のグループ機能では、**「1グループあたりの最大人数を 5人 に制限する（`maxMembers: 5`）」**という設計を採用しています。

また、アプリの実際の運用データや利用者の観察から、**「親友や恋人、家族など、もともと信頼関係のあるグループは継続率が高く、見知らぬ人同士や関係性の薄いグループは長続きしにくい」**という傾向が見られました。

本ドキュメントでは、なぜ5人という少人数に設定しているのか、そしてグループ内の関係性が習慣化にどう影響するのかを考察します。

---

## 1. なぜ「最大人数 5人」なのか？

一般的なソーシャルサービスでは数十人以上の大きなグループを作れることが多いですが、日々の習慣づくりや内省を共有する場においては、人数が多すぎると以下のような課題が生じます。

```mermaid
graph TD
    subgraph 人数が多いグループ（20〜100人）
        A1[人数が多い] --> B1[「誰かがやるだろう」という気の緩み]
        B1 --> C1[誰も発言・リアクションしなくなる]
        C1 --> D1[グループの過疎化・自然消滅]
    end

    subgraph Scripture Habit（最大5人）
        A2[5人の少人数] --> B2[個人の参加状況が見えやすい]
        B2 --> C2[スタンプやエールで反応しやすい]
        C2 --> D2[お互いに習慣が続きやすい]
    end

    style D1 fill:#ffebee,stroke:#c62828,stroke-width:1px
    style D2 fill:#e8f5e9,stroke:#2e7d32,stroke-width:1px
```

### ① 社会的手抜き（リンゲルマン効果）の防止
集団の人数が増えるほど、「自分がやらなくても全体の成果にあまり影響しない」と感じて個人の貢献度が下がってしまう現象（社会的手抜き）があります。
人数が多いグループでは「1日くらいサボっても目立たない」となりがちですが、**5人程度の少人数であれば、お互いの参加状況が自然と把握でき、良い意味での責任感（ピア・アカウンタビリティ）が働きます。**

### ② 傍観者効果を防ぎ、リアクションしやすい環境を作る
大人数のチャットでは「他の誰かが返事をするだろう」と全員が様子見になりがちです。
5人グループであれば「自分たちで場を盛り上げよう」という意識が自然に生まれ、スタンプやエール（Cheer）による励まし合いが起こりやすくなります。

### ③ 親密な関係を保てる規模（ダンバー数）
人類学の研究（ダンバー数）でも、人間が気を遣わずに本音で深く関わり合える親密なグループの規模は「約5人まで」と言われています。

---

## 2. 信頼関係の深さと継続率の違い

実際の運用で特に顕著だったのは、**「メンバー同士の関係性」が継続率に大きく関わっている**という点です。

```mermaid
graph LR
    subgraph 親友・恋人・家族
        ST1[もともと信頼関係がある] --> ST2[短いメモでも気兼ねなく投稿できる]
        ST2 --> ST3[相手の投稿を見るのが楽しみになる]
        ST3 --> ST4[長く続きやすい]
    end

    subgraph 見知らぬ人同士
        WT1[お互いをよく知らない] --> WT2[「変なことを書けない」と構えてしまう]
        WT2 --> WT3[1人が休むと他の人も休みがちに]
        WT3 --> WT4[自然消滅しやすい]
    end

    style ST4 fill:#e8f5e9,stroke:#2e7d32,stroke-width:1px
    style WT4 fill:#ffebee,stroke:#c62828,stroke-width:1px
```

### ① 親友・恋人・家族グループが続きやすい理由
- **気兼ねなく投稿できる安心感（心理的安全性）**:
  親しい間柄であれば、「こんな短い感想で変に思われないか」といった心配がいりません。1行の短いメモでも気軽に共有できます。
- **お互いを応援し合うモチベーション**:
  大切な人が学習している様子を見ることで「自分も読もう」と自然に思えたり、相手の感想を読むこと自体が楽しみになったりします。

### ② 見知らぬ人同士のグループが直面しやすい課題
- **投稿に対するプレッシャー**:
  知らない人が相手だと、「きちんとした文章を書かなければいけない」と気負ってしまい、ノートを書くハードルが上がってしまいます。
- **休止の連鎖**:
  誰か1人が数日間投稿をやめると、「あ、休んでもいいんだ」という空気が広がり、他のメンバーも投稿をやめてしまう傾向があります。

## 3. アプリの設計と工夫

こうした知見を踏まえ、Scripture Habit では以下のような工夫を取り入れています。

| 設計・機能 | 狙い |
| :--- | :--- |
| **最大5人の人数制限（`maxMembers: 5`）** | 責任の分散を防ぎ、全員が顔の見える関係を保てるようにする。 |
| **親しい人への招待リンクの活用** | 親友やパートナー、家族を直接招待して一緒に始められるようにする。 |
| **AIパートナーボットの参加** | 見知らぬ人同士のグループや人数が少ないグループでも、AIが毎日投稿して場の沈黙を防ぐ。 |
| **Unity（団結度）の仕組み** | 個人同士の順位争いではなく、「全員で何％読めたか」という協力型の目標にする。 |
| **長期間不活動なメンバーの自動整理** | 幽霊メンバーが残ることでグループ全体の活動が止まるのを防ぐ。 |

---

## 4. まとめ

習慣を続ける上では、個人の意志だけでなく、**「誰と一緒に取り組むか」**という環境が大きな影響を与えます。

Scripture Habit は、不特定多数の大きなコミュニティを作るのではなく、**「身近な大切な人と、あるいは自分のペースで気兼ねなく続けられる温かい5人までの空間」**を提供することを目指しています。
