# UI/UX デザインシステム

**scripture-habit** のデザイン言語は、グラデーション、半透明のガラス効果（グラスモーフィズム）、およびシンプルなアニメーションを使用して、モダンなインターフェイスを作成しています。

---

## カラーパレット (Color Palette)

すべてのコアスタイルは、CSS変数を使用して `src/index.css` に一元管理されています。

### カラーパレットトークン
- **ブランドカラー (Brand Colors)**:
  - `--pink`: ハイライトやアクティブ状態に使用されます。
  - `--purple`: （グラデーション用）プライマリアクションに使用されます。
  - `--yellow`: （グラデーション用）実績やコインに使用されます。
- **サポートカラー (Support Colors)**:
  - `--black`: (#242d49) テキストや高コントラスト用の深いネイビー。
  - `--gray`: セカンダリテキストやヒント用のソフトグレー。
  - `--red`: アラートやエラー用の赤。

### 背景とグラデーション (Backgrounds & Gradients)
メインアプリの背景は、3色のグラデーションです：
```css
background: linear-gradient(106.37deg, #feac5e 29.63%, #c779d0 51.55%, #4bc0c8 90.85%);
```

## グラスモーフィズム (グラスカード)

UIは、レイアウトの奥行きを表現するために、半透明の「グラスカード（Glass Card）」効果を使用しています。

### `.AppGlass`
すべての画面のプライマリコンテナ：
- **背景 (Background)**: `rgba(255, 255, 255, 0.54)`
- **ぼかし (Blur)**: （注意）以前は `backdrop-filter: blur(20px)` が適用されていましたが、子要素の `position: fixed` の配置にバグ（親要素のフィルターによって fixed が absolute のように動作する問題）が発生するため、現在は無効化されています。
- **影 (Shadow)**: `--boxShadow` が柔らかく浮かび上がるような浮遊感を与えます。

### デザインルール
新しいカードやモーダルを追加する場合は、`var(--glass)` を使用し、角丸（border-radius）を `2rem` または `16px` に設定して、クリーンで丸みのある外観を維持してください。

## モバイルファースト戦略

アプリは、デスクトップと（Capacitor を介した）モバイルの両方で完全に機能するように設計されています。

### ブレイクポイント: 768px
- **デスクトップ**: サイドバーは固定され、コンテンツは中央揃えになります。
- **モバイル**:
  - モバイル画面での視認性を向上させるため、グラス効果はソリッドまたは半透明の白背景（`rgba(255, 255, 255, 0.95)`）に置き換えられることがよくあります。
  - UIがモバイルのステータスバーやカメラのノッチと重なるのを防ぐために、`env(safe-area-inset-top)` が使用されます。

## パターンとアニメーション

### 1. 「シェイク（揺れ）」アラート
エラー（ログイン失敗など）が発生すると、`index.css` で定義された `shake` アニメーションがトリガーされ、即座に視認性の高いフィードバックを提供します。

### 2. UIトランジション
- **ホバー (Hover)**: アイコンやボタンは、CSSトランジション（`0.2s`）を使用して、わずかにスケールが変更されるか、不透明度が変化します。
- **アクティブ (Active)**: 選択されたアイテムは `var(--activeItem)` を使用します。

### 3. タイポグラフィ (Typography)
- **プライマリフォント (Primary Font)**: `Inter`, sans-serif。クリーンで、小さなサイズでも読みやすいフォントです。
- **見出し (Headings)**: 見出し（`h1`、`h2`）は、レイアウトをすっきりとさせ、スキャンしやすくするために、窮屈さを避けた行間隔を使用しています。
